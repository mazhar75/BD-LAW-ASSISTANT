# Frontend

This directory contains the React.js Single Page Application (SPA) for BD Law Assistant.

## Features
- Search bar for legal queries
- Conversational chatbot UI
- Bengali language support
- Integration with API Gateway for backend services

## Structure
- `src/` - Main React source code
- `public/` - Static assets

## Setup
1. Ensure you have Node.js (v16+) and npm installed.
2. Install dependencies:
   ```
   npm install
   ```
3. Start the development server:
   ```
   npm start
   ```

## Build
To create a production build:
```
npm run build
```
