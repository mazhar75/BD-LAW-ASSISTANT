# Vector Store

This directory contains scripts and configuration for the semantic vector store used by BD Law Assistant.

## Purpose
- Stores high-dimensional embeddings of legal text chunks
- Supports FAISS, Pinecone, or Weaviate as backend
- Enables fast semantic search and retrieval

## Usage
- See scripts/config files for setup and migration
- Used by the RAG microservice for retrieval

## Configuration
- Edit config files for backend selection and credentials
